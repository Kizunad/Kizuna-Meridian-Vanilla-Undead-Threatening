# 白僵、黑僵和毛僵

成年僵尸、尸壳、溺尸、僵尸村民和僵尸猪灵都有尸身。它们仍按原版方式寻找目标、出手和掉落物品。幼体沿用原版血量。

尸身的部位和人相同，腹中另有一颗尸丹。野外自然出现的成年个体大多是白僵。当地难度越高，遇见黑僵和毛僵的机会越大，毛僵最少见。普通刷怪蛋、刷怪笼、援兵和结构默认生成白僵。猪灵僵化时保留道行，金肤转黑僵，金骨转毛僵。出生持金剑的黑僵僵尸猪灵学流金剑上卷，毛僵学上下卷。

| 道行 | 出生时的经脉 | 尸丹 |
|---|---|---|
| 白僵 | 经脉未开 | 空丹，能存十元 |
| 黑僵 | 任脉、左右肺经、左右胃经已开 | 生来带十元，能存二十元 |
| 毛僵 | 已入真炁境，除黑僵的五条经脉，左右大肠经、左右脾经和督脉也已开通 | 生来带二十元，能存四十元 |

三种尸身都照原版的方式出手。头、颈、胸有一处被打空，或全身部位所剩的血量少于两成，就会死。单独打坏心、肺、脑或尸丹仍能活。

黑僵和毛僵生来会拜月诀的纵和铜皮。纵须躯干、左右腿经脉都已开通，起手从尸丹付三元；
铜皮须躯干、左右臂经脉都已开通，起手付五元。白僵和活人的清单里没有这两式。
尸丹空了、碎了，或腹部失能时，已经会的式仍在清单里，起手会失败。

持金剑的尸修施「绕」时要有已开的手经，三元剑费从尸丹支出。其他原本由经脉供元的式也由尸丹付款，仍需满足各式的真元属性与形态要求。

锁定目标能看到它的名字。用肢体透视镜可查看各部位的名称和血量。管理员可以对准目标执行 `/meridian body undead inspect`，或在末尾加一个实体选择器，查看道行、已开经脉、部位血量、尸丹容量和存元。用 `/meridian humanoid spawn husk true_qi` 能直接造一只毛僵尸壳。指令中的 `mortal`、`wandering_qi`、`true_qi` 分别对应白僵、黑僵、毛僵。

打空一个部位以后，多出的伤害会按人体同样的部位系数传到其他部位。服主可以在 `meridian-human-damage.toml` 中为尸身模板单配这一规则。

## 物种开关

`config/meridian-undead.toml` 中的 `zombie`、`husk`、`drowned`、`zombie_villager`、`zombified_piglin` 分别控制这五种尸身，默认均为 `true`。修改后执行 `/reload`。关闭时该种新个体沿用原版血量，已有尸身随实体封存。重新开启后，原来的伤势仍在。

旧配置缺少的开关采用随包默认值。键名写错时，重载会指出该键。

僵尸泡水转为溺尸、尸壳转为僵尸、村民与僵尸村民相互转化时，旧身体随原实体释放，新实体按自己的物种另得一具身体。

## 受签夜访

剧情宿主核对正在夜行的持货者、原物签号及场位后，调用 `NightVisits.request(player, ticket, feet)`。主世界夜间有安全站位才生成一只原版成年僵尸，只有返回 PRESENT 才算到场。等待中可以重试原签。签号确定实体 UUID，世界保存目标、位置与战果，实体也保存签号和物主。

`NightVisits.status(player, ticket)` 可重查在场、暂挂和胜逃败。卸载时暂挂，重新加载后继续同一夜访。亡灵实际死亡记胜，双方在场时本人脱离追击距离或维度记逃，该亡灵击杀持货者记败。终局保留原签回执。[夜访入口](../../fabric/src/main/java/dev/kizuna/meridian/undead/fabric/NightVisits.java)
